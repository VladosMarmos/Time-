МОЁ ВРЕМЯ — установка и публикация

ЧТО ВНУТРИ
- index.html — страница приложения
- styles.css — оформление
- app.js — логика счётчиков
- manifest.webmanifest + sw.js + icon.svg — установка как PWA и офлайн-кэш

КАК РАБОТАЕТ
- Можно добавить много событий с названием, датой и временем.
- Счётчики обновляются каждую секунду.
- Показываются годы, месяцы, дни, часы, минуты и секунды.
- Данные хранятся в localStorage браузера на этом устройстве.
- Есть удаление, сортировка и переключение темы.
- Будущие даты тоже поддерживаются: показывается обратный отсчёт.

ПУБЛИКАЦИЯ БЕСПЛАТНО ЧЕРЕЗ GITHUB PAGES
1. На телефоне открой https://github.com/ и создай бесплатный аккаунт или войди.
2. Нажми + → New repository.
3. Назови репозиторий time-counter, выбери Public и нажми Create repository.
4. В репозитории выбери Add file → Upload files.
5. Распакуй архив на телефоне и загрузи ВСЕ файлы из папки time-counter-app (не саму папку).
6. Нажми Commit changes.
7. Открой Settings → Pages.
8. В разделе Build and deployment выбери Deploy from a branch.
9. Branch: main; Folder: /(root); нажми Save.
10. Подожди публикацию. Ссылка будет вида https://ТВОЙ-ЛОГИН.github.io/time-counter/

УСТАНОВКА НА ANDROID
1. Открой опубликованную ссылку в Chrome.
2. Меню ⋮ → «Добавить на главный экран» или «Установить приложение».
3. Подтверди установку.

ВАЖНО
- Для PWA и офлайн-режима нужен опубликованный HTTPS-сайт (GitHub Pages подходит).
- Счётчики сохраняются локально в браузере/на устройстве. Очистка данных сайта или переход на другой браузер/телефон может удалить или не перенести их. Экспорт/облачная синхронизация пока не реализованы.
- Не публикуй личные данные в названиях событий, если не хочешь хранить их в браузере.
